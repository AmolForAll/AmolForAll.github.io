## 🎨 Customizing Your Portfolio Website

### Change Colors

1. Edit `styles.css`
2. Find `:root` section at the top
3. Update color variables:
   ```css
   :root {
       --primary-color: #667eea;      /* Change this */
       --secondary-color: #764ba2;    /* Or this */
   }
   ```
4. Save and refresh

### Add More Services

1. Edit `index.html`
2. Find the services section
3. Duplicate a service card and update:
   ```html
   <div class="service-card">
       <div class="service-icon"><i class="fas fa-ICON"></i></div>
       <h3>Your Service</h3>
       <p>Description</p>
   </div>
   ```
4. Find icons at [fontawesome.com](https://fontawesome.com/icons)

### Add Your Skills

1. Edit `index.html`

4. Save and refresh
